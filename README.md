# Signalcast

실시간 코인 시세와 해외 뉴스의 코인별 영향 분석을 한 화면에서 보는 것을 목표로 하는 무료 정보 대시보드입니다.

지금은 1차 기능인 **김치 프리미엄 대시보드**를 만들고 있습니다. 업비트·바이낸스 실시간 시세로 코인별 김치 프리미엄을 보여줍니다.
뉴스 영향 분석과 그 밖의 기능은 아직 구현하지 않았으며, [로드맵](#로드맵)에 계획으로만 적어 두었습니다.

> **투자 조언이 아닌 참고 정보이며, 투자 판단의 책임은 본인에게 있습니다.**
> Signalcast는 매매를 권유하지 않는 정보·분석 도구입니다.

## 상태: 개발 중 (2026-11-24 기준)

공개된 데모 사이트는 아직 없습니다.

**1차 기능 중 지금 동작하는 것** (로컬 빌드를 헤드리스 Chrome으로 열어 확인)

- 업비트·바이낸스 공개 WebSocket으로 BTC, ETH, XRP, SOL, DOGE의 실시간 가격 수신 (브라우저가 거래소에 직접 연결)
- 코인별 김치 프리미엄(공식 환율 기준)과 테더 김프(업비트 USDT 가격 기준)를 나란히 표시
- ECB 기준 USD/KRW 환율과 기준일 표시 (주말·휴일에는 직전 영업일 값이라는 안내 포함)
- 거래소별 연결 상태 표시

**구현했지만 단위 테스트로만 확인한 기능**

- 연결이 끊기면 지수 백오프로 자동 재연결 (업비트는 브라우저 요청 제한에 맞춰 최소 10초 간격)
- 연결이 끊겼거나 시세가 1분 넘게 멈추면 "지연" 표시

모바일 화면은 아직 확인하지 않았습니다.

## 로드맵

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1차 | 업비트·바이낸스 실시간 시세로 김치 프리미엄 대시보드와 알림. 남은 것: 김치 프리미엄 추이 차트, 기준값을 넘을 때의 알림, 모든 화면 하단의 면책 문구와 시세·환율 출처 표시 (지금은 이 README에만 있음) | 진행 중 |
| 2차 | 서버가 해외 뉴스를 주기적으로 수집하고, LLM이 코인별 영향(긍정/부정/중립, 확신도, 근거 한 줄)을 판정해 캔들 차트 위에 표시 | 예정 |
| 3차 | 과거 뉴스 영향 판정과 이후 실제 가격 움직임을 비교하는 "분석 검증" 화면 (맞은 것과 틀린 것을 표본 수·기간과 함께 모두 표시) | 예정 |
| 4차 | 바이낸스 읽기 전용 API 키로 개인 포지션을 불러와, 뉴스 영향과 방향이 반대일 때 본인에게 알림 (개인용 기능이며 공개 배포에서는 꺼짐) | 예정 |

운영 원칙

- 광고, 후원 배너, 거래소 추천인(레퍼럴) 링크를 넣지 않습니다.
- LLM은 서버의 정해진 주기 작업에서만 호출하고 결과를 저장해 재사용합니다. 방문자 요청이 LLM 호출로 바로 이어지지 않습니다.

## 데이터 출처와 약관

| 데이터 | 출처 | 받는 방식 |
| --- | --- | --- |
| 원화 마켓 시세 | 업비트 공개 WebSocket | 방문자 브라우저가 직접 연결 |
| USDT 마켓 시세 | 바이낸스 공개 WebSocket | 방문자 브라우저가 직접 연결 |
| USD/KRW 환율 | ECB(유럽중앙은행) 기준환율, [Frankfurter API](https://frankfurter.dev) 경유 | 방문자 브라우저가 직접 조회 |

- 시세 데이터의 권리는 각 거래소에 있으며, 시세 데이터 이용은 각 거래소(업비트, 바이낸스)의 이용약관을 따릅니다.
- 이 프로젝트의 서버는 시세를 받거나 저장하지 않으며, 시세를 다시 제공하는 API나 프록시를 두지 않습니다.
- ECB 기준환율은 TARGET 영업일에 하루 한 번 발표되며, ECB는 이 값을 정보 제공 목적으로 발표합니다. USD/KRW는 EUR 기준 환율에서 교차 계산한 값입니다.
- 코드의 라이선스(MIT)는 위 데이터에 적용되지 않습니다.

## 기술 스택

- npm workspaces 모노레포
  - `web/` — Vite, React, TypeScript (strict)
  - `server/` — Node, Hono, TypeScript (strict). 지금은 상태 확인(`/health`)과 환경변수 검증만 있으며, 2차부터 사용합니다.
- 테스트: Vitest / 린트: oxlint
- 예정: 캔들·추이 차트에 [Lightweight Charts](https://github.com/tradingview/lightweight-charts)

## 실행 방법

Node.js 22.12 이상이 필요합니다.

```bash
npm install

# 웹 개발 서버 (http://localhost:5173)
npm run dev:web

# 테스트, 타입 검사, 린트, 빌드
npm test
npm run typecheck
npm run lint
npm run build
```

API 키는 필요 없습니다. 서버(`server/`)를 따로 실행하려면 `server/.env.example`을 `server/.env`로 복사한 뒤 `npm run dev:server`를 실행합니다. `.env` 파일은 커밋하지 않습니다.

## 프로젝트 구조

```
web/src/
├─ app/                     # 화면 골격, 스타일
├─ features/kimchiPremium/  # 김치 프리미엄 계산, 추적 코인 목록, 화면
└─ shared/
   ├─ exchanges/            # 업비트·바이낸스 WebSocket, 자동 재연결
   ├─ exchangeRate/         # ECB 기준 USD/KRW 조회
   ├─ market/               # 거래소 연결을 묶는 시세 스토어
   └─ format/, hooks/, ui/
server/src/                 # Hono 서버 골격 (2차부터 사용)
```
